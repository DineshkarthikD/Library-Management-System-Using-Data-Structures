📚 Library Management System

A standalone desktop application developed using Python and Tkinter for efficient library management. This project was developed as part of a Data Structures Fundamentals: Basics to Applications summer internship.

📖 Project Overview

The Library Management System is designed to automate the daily operations of a library. It allows librarians to manage books and members, issue and return books, search records efficiently, and maintain transaction history through a simple graphical user interface.

The project demonstrates the practical implementation of Object-Oriented Programming (OOP), File Handling, GUI Development, and Data Structures.
